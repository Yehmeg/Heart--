# 💖 Mathematical Heart using Python Turtle
A Python Turtle Graphics project that uses mathematical equations to generate a colorful heart-shaped design.💗💫💓💖💝


A colorful heart-shaped design created using **Python Turtle Graphics** and mathematical equations. The project combines basic Python programming, trigonometry, loops, and Turtle graphics to generate a visually appealing heart pattern.

## ✨ Features

- 🎨 Colorful heart-shaped design
- 🐢 Built using Python Turtle Graphics
- 📐 Uses mathematical equations to generate heart coordinates
- 🔄 Uses loops to create the complete pattern
- 🌈 Randomly selects colors for different drawing strokes
- ⭐ Creates a starburst effect at each point of the heart

## 🛠️ Technologies Used

- **Python**
- **Turtle Graphics**
- **Math**
- **Random**

## 🧠 How It Works

The project uses a mathematical heart curve to calculate the coordinates of points along the heart.

The equations used are:

```text
x = 16sin³(t)

y = 13cos(t) - 5cos(2t) - 2cos(3t) - cos(4t)

```
